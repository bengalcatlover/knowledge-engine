## コース別の重心

- **24.08J Philosophical Issues in Brain Science**
  - 心の哲学、意識、知覚、認知科学の概念整理が中心。
  - ビジネス応用では、AIの「知能」やユーザーの「理解」を分解して考えるために有用。
  - 脳科学の実験手法そのものよりも、理論的な問いと概念分析に重心がある。

- **24.908 Creole Language and Caribbean Identities**
  - クレオール言語とカリブ海のアイデンティティ、言語と社会的帰属、対話設計が中心。
  - 言語の標準／非標準という分類が、権力や差別とどう結びつくかを考える入口になる。
  - 言語学の形式分析より、社会言語学・教育・アイデンティティ寄り。

- **24.912 Introduction to Black Studies**
  - 人種、社会正義、言語、政治経済、移民、ポピュリズム、ビッグデータ、権利を横断する。
  - この3コースの中では、企業・プラットフォーム・公共政策への接続が最も広い。
  - 一方で、タイトル上は政治的・批判的分析が強く、黒人史・文学・経済史・地域別研究の体系性は限定的。

| **Molyneuxの問い：感覚間の知識移転** | ある感覚で学習した概念が、別のインターフェースやモダリティでも利用できるかを検証する | 触覚で覚えたボタン配置を音声UIや視覚UIに移せるかを検証し、視覚障害者向けアプリのオンボーディングを設計する |
| **乳児を「小さな科学者」とみなす学習モデル** | ユーザーや顧客が、観察・試行・フィードバックから仮説を更新する存在だと考える | 新規ユーザーに一度に長い説明を読ませず、複数の短い操作を試させ、行動から意図を推定するアクティブ・ラーニング型オンボーディングを作る |
| **意識と知能の切り分け** | 「高度に応答する」ことと「主観的経験がある」ことを区別する | AI製品の要件定義で、性能・自己報告・メタ認知・主観的意識を別々の評価軸にする。「意識を持つAI」といった過剰なマーケティング表現を避ける |
| **言語とアイデンティティの分析** | 方言、クレオール、コードスイッチング、アクセントを「ノイズ」ではなく、顧客属性・文化・信頼のシグナルとして扱う | 音声認識AIで特定の方言やアクセントの誤認識率を測定し、標準語話者だけでなく地域・民族ごとに性能を評価する |
| **言語を抵抗・解放の手段として捉える視点** | 企業の用語、分類、命名が、誰を可視化し誰を排除しているかを検証する | 採用システムで「ネイティブ」「文化適合性」などの曖昧な表現を見直し、言語的・文化的な同質性を能力と誤認しない基準に変える |
| **意味のある対話のファシリテーション** | 会議やワークショップを、声の大きい人の意見を採用する場ではなく、異なる経験と証拠を比較する場として設計する | AI導入の社内会議で、現場の懸念、法務上の制約、経営指標を別々に収集し、論点・合意点・未解決点を記録する |
| **文化を社会的テクノロジーとして見る** | 文化や慣行を固定的な「社風」ではなく、行動を再生産する仕組みとして分解する | 営業組織の「顧客対応の文化」を、評価制度、会議、インセンティブ、使われる言葉、成功事例の共有方法に分解し、変更可能な要素を特定する |
| **批判的コンピュテーション** | データやアルゴリズムを使うだけでなく、誰が分類し、誰が利益を得て、誰が不利益を受けるかを監査する | 与信・採用・広告配信モデルについて、属性別のエラー率、除外率、説明可能性、異議申立ての手段を確認する |
| **ダークポスト／不可視の政治広告の分析** | 個別ユーザーにだけ見えるメッセージが、公共的な議論や説明責任をどう変えるかを分析する | 政治広告に限らず、金融商品・健康商品・求人広告のマイクロターゲティングについて、広告主、対象条件、表示内容、配信差分を監査する |
| **新自由主義・ポピュリズム・分極化のフレーム** | 市場や製品の問題を、価格・機能だけでなく、格差、不信、政治的怒り、制度への不満の文脈で読む | 新興国へのサービス展開で、規制だけでなく、移民政策、反エリート感情、プラットフォーム不信が採用率や炎上リスクに与える影響を分析する |
| **人権・投票権の視点** | 成長や効率化の前に、サービスへのアクセス、政治参加、差別されない権利を確認する | 公共サービスのチャットボット導入時に、言語、障害、在留資格、デジタルアクセスの違いで申請機会が失われないかを点検する |
| **個人的経験と構造分析の接続** | 定量データだけでなく、当事者の経験を制度・歴史・設計上の問題と結び付ける | 顧客満足度が高くても、特定コミュニティの自由記述に繰り返し同じ排除体験が出ていれば、平均値で埋もれた問題として調査する |
| **学際的な問題分解** | 1つの専門用語やKPIで問題を閉じず、技術、言語、制度、歴史、経験を同時に見る | AI採用支援の問題を、モデル精度だけでなく、職務記述の言語、過去の採用慣行、法的責任、候補者の信頼まで分解する |

## コンサルティングでの利用例

「ある企業のAI導入が特定のコミュニティに不信感を持たれている」という案件では、次の順番で使える。

1. **認知科学**：ユーザーはAIを何だと理解しているか。単なる検索ツールか、意思決定者か。
2. **言語・アイデンティティ**：説明文や音声UIが、特定の文化・方言を標準としていないか。
3. **批判的コンピュテーション**：データ、分類、配信、異議申立てのどこで権力差が発生しているか。
4. **人権・権利**：誤判定が、単なる不便ではなく就労・教育・投票・公共サービスへのアクセスを損なわないか。
5. **対話設計**：技術者だけでなく、現場・利用者・コミュニティ・法務を含めて意思決定する。

# 4. 薄い／ない領域

## 言語学の基礎体系

このコース群は「言語とアイデンティティ」「言語と政治」には触れるが、言語学の中核である以下はほぼ扱っていない。

- 音声学・音韻論
- 形態論・統語論
- 形式意味論・語用論
- 言語変化・比較言語学
- 社会言語学の定量的方法
- 言語記述・フィールドワーク
- クレオール化の構造的・歴史的メカニズム
- コーパス言語学、自然言語処理、言語モデル

したがって、音声認識やLLMの品質改善に直結させるには、別途、方言・コードスイッチング・言語データの構造を学ぶ必要がある。

## 哲学の広い領域

24.08Jは心の哲学・意識・知覚に集中しており、以下は薄い。

- 認識論、知識と正当化
- 倫理学、応用倫理、AI倫理
- 論理学・議論分析
- 科学哲学・因果性
- 自由意志、人格、自己同一性
- 哲学的な意思決定理論
- 政治哲学の体系的な比較

AI製品の責任や企業倫理に応用する場合は、功利主義、義務論、徳倫理、正義論、責任論などを追加する必要がある。

## 脳科学・認知科学の実験手法

意識や乳児認知についての問いは扱うが、以下の実務的な方法は十分ではない。

- fMRI、EEG、単一細胞記録などの神経科学手法
- 実験計画、統計的検定、再現性
- 認知モデルの実装
- 注意、記憶、学習、意思決定の実験パラダイム
- 臨床神経科学や精神医学

理論をAIやUXに移す場合、理論的な類推だけでなく、ユーザーテストや行動データで検証する必要がある。

## AI・データサイエンスの技術

`24.912`にはデータと政治の批判的分析があるが、次の技術は扱われていない、または薄い。

- 機械学習アルゴリズム
- 大規模言語モデル
- 推薦システム
- 因果推論
- 公平性指標とバイアス緩和手法
- プライバシー保護技術
- データパイプライン、MLOps、モデル監視
- AI評価ベンチマーク
- コンテンツモデレーションの実装

そのため、「アルゴリズムが社会に与える影響を問う」ことはできるが、「どのモデルをどう直すか」には別の技術知識が必要。

## 黒人研究の歴史・地域・文化の体系性

`24.912`は社会正義、新自由主義、ポピュリズム、ビッグデータなどを横断するが、提示タイトルからは以下が中心テーマとしては見えにくい。

- アフリカ・ディアスポラの地域別歴史
- 黒人文学・音楽・美術・映画
- 奴隷制・植民地主義の経済史
- ジェンダー、セクシュアリティ、障害との交差性
- アフリカ大陸の政治・経済
- 黒人企業、労働、市場形成
- 黒人コミュニティ内部の多様性

「黒人コミュニティ」を単一の市場・政治主体として扱わないためには、これらの補強が必要。

## 実証的なビジネス応用

以下はほとんど扱われていない。

- 顧客インタビュー、観察、エスノグラフィー
- 市場規模、価格、競争分析
- 組織設計、インセンティブ、チェンジマネジメント
- ROIやKPIの設計
- 施策の実装・運用
- 法務、コンプライアンス、リスク管理
- 企業内での意思決定プロセス

この知識群は「何を問題として見るべきか」を広げるのに強いが、「施策をどの順番で実装し、成果をどう測るか」は別途補う必要がある。

| **自然言語処理・音声AI** | クレオール、方言、コードスイッチング、言語とアイデンティティ | 標準語中心のデータセットによる性能格差を検出し、話者集団別のWER、意図認識率、再質問率を測定する |
| **社会言語学** | 言語の標準／非標準、言語と社会的地位、言語実践と権力 | 顧客対応や採用で、アクセント・語彙・文体を能力と誤認していないかを調べる |
| **政治学・政治経済学** | 新自由主義、ポピュリズム、分極化、移民、権利 | 市場参入や政策提言で、規制だけでなく、制度不信、反エリート感情、移民政策、政治的分断をリスク要因として組み込む |
| **プラットフォーム・広告ガバナンス** | ダークポスト、ビッグデータ、不可視のターゲティング | 広告の配信対象、表示メッセージ、除外条件、広告主、ユーザーへの説明を監査し、マイクロターゲティングによる差別や操作を検証する |
| **法務・公共政策** | 人権、投票権、アクセス、参加、説明責任 | AIや公共サービスの導入を、個人情報保護だけでなく、平等なアクセス、救済手段、政治参加への影響から評価する |
| **組織行動・人材マネジメント** | 対話のファシリテーション、文化を社会的テクノロジーと見る視点 | 組織文化を「変えにくい性格」ではなく、評価制度、会議、言葉、インセンティブから成る設計対象として扱う |
| **教育・ラーニングデザイン** | 乳児＝小さな科学者、意味のある対話、知識の公共化 | 学習者が試行錯誤しながら仮説を更新できる教材や研修を作り、発言者の偏りを抑えた対話型研修を設計する |
| **マーケティング・ブランド戦略** | アイデンティティ、言語、物語、ポピュリズム | 顧客コミュニティを単なる属性セグメントではなく、歴史・言語・帰属意識を持つ主体として理解し、表層的な文化表現を避ける |
| **コンサルティング・戦略** | 学際的分析、個人的経験と構造の接続、政治経済的コンテキスト | 経営課題を、機能・価格・組織だけでなく、制度、歴史、言語、権利、当事者経験の組み合わせとして診断する |
| **リサーチ・評価設計** | 理論と経験の区別、複数の表象、批判的なデータ読解 | 定量KPIの平均値で少数者の不利益を隠さず、自由記述、インタビュー、属性別エラー率、異議申立て率を併用する |

## 接続時の注意

この分野の概念は、直ちに売上やモデル精度を予測するものではない。特に哲学・批判理論の役割は、次のような「問題設定の漏れ」を発見することにある。

- 何を知能・理解・意識と呼んでいるのか
- 誰の言語や経験を標準としているのか
- どのユーザーがデータ上で不可視になっているのか
- 効率化の裏側で、誰の権利や参加機会が損なわれているのか
- 平均値や総合KPIによって、少数者の失敗が隠れていないか

実際の施策に落とす際は、これらの問いを、ユーザー調査、実験、モデル監査、法的レビュー、運用KPIと組み合わせる必要がある。
