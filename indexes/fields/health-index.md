### コース全体の位置付け

- **臨床医学の入門コースではない。**
- **SUDの病態、治療法、疫学を体系的に学ぶよりも、SUD領域の課題を起業・事業化・イノベーションの対象として扱うコース**である。
- 深い専門性は、以下の領域に集中している。
  - 医療研究から事業への翻訳
  - 医療現場の課題発見
  - ユーザー／当事者主導の設計
  - 医療システム内での導入
  - 薬剤不正流用などの安全・管理課題

## 使える武器

### 1. 医療現場の「損失」を事業機会へ変換する

医療の問題を、単なる社会課題ではなく、以下のような損失構造に分解できる。

- 金銭的損失
- 医療事故リスク
- 業務時間の損失
- 患者アウトカムの悪化
- 法規制・監査上のリスク
- 医療者や患者の信頼低下

**具体例：薬剤不正流用**

病院内の薬剤不正流用を、以下の指標で可視化する。

- どの部署・時間帯・職種で異常が多いか
- 処方量と実際の投与量の差
- 廃棄記録と在庫記録の不一致
- 同一人物による例外操作の頻度
- 薬剤の移動経路における監査不能箇所

これを基に、異常検知、アクセス制御、在庫照合、監査ワークフローなどの製品仮説を作る。

### 2. Research-to-venture翻訳

研究成果をそのまま製品と見なさず、次の順番で翻訳する。

1. 研究上の発見は何か
2. 誰のどの意思決定を改善するのか
3. 現場の既存ワークフローのどこに組み込むのか
4. 導入によって何が改善するのか
5. 誰が費用を負担するのか
6. 有効性・安全性をどのように検証するのか

**AI製品への応用例**

SUD患者の再発リスク予測モデルを作る場合、モデル精度だけでは不十分である。

- 医師が診療中に解釈できるか
- 誤検知が患者への偏見や不適切な介入を生まないか
- 患者の同意を得られるか
- 電子カルテに組み込めるか
- 予測結果に対して何の介入を行うか
- 保険者・病院が費用を負担するか

まで含めて事業化可能性を評価する。

### 3. ユーザー開発型イノベーション

ユーザーが自分の問題を解決するために作っている道具・運用を、正式な製品開発の起点として扱う。

**応用例**

SUD当事者や支援者が、以下のような独自の運用を作っている場合を考える。

- 再発トリガーを記録する簡易ツール
- 服薬・通院を支援するリマインダー
- ピアサポートの連絡網
- 過量摂取時の緊急連絡フロー
- 医療者に相談しやすくする質問テンプレート

これらを観察し、ユーザーが本当に解決したい問題を特定する。企業側が最初から製品仕様を決めるのではなく、現場の工夫を標準化・安全化・拡張する。

### 4. 医療ステークホルダーの利害を分離して設計する

ヘルスケアでは、利用者、意思決定者、支払者、規制者が一致しない。

| ステークホルダー | 関心 |
|---|---|
| 患者・当事者 | アクセスしやすさ、プライバシー、尊厳、実際の効果 |
| 医師・看護師 | 臨床的有用性、業務負荷、責任範囲 |
| 病院経営者 | コスト、収益、事故・監査リスク |
| 保険者・行政 | 再入院率、医療費、集団全体のアウトカム |
| 研究者 | エビデンス、再現性、論文化 |
| 規制当局 | 安全性、品質、説明責任 |
| 家族・支援者 | 継続的支援、危機時の対応 |

**コンサルティングへの応用**

新しいSUD支援サービスを病院に導入する際、患者インタビューだけでなく、病院経営層、臨床現場、医療ソーシャルワーカー、保険者、地域支援機関を別々に調査し、導入阻害要因をマップする。

### 5. ケーススタディから事業化の勝ち筋を抽出する

ケースを単なる成功物語として読まず、次の観点で比較する。

- 顧客の痛みはどれほど強いか
- 技術は代替困難か
- 導入者と支払者は誰か
- 現場の業務フローをどれだけ変えるか
- エビデンスがどの時点で必要か
- 規制・認証が成長速度に与える影響
- 初期顧客をどのように獲得したか
- 医療機関内での意思決定期間はどれほど長いか

これは、医療AI、診断、院内安全、創薬支援、デジタル治療などにも転用できる。

### 6. 医療導入の「実験単位」を小さくする

いきなり全病院への導入を目指さず、以下のように導入範囲を限定する。

- 1つの病棟
- 1種類の薬剤
- 1つの患者群
- 1つの診療フロー
- 1つの異常パターン

**例：薬剤監視システム**

最初は「全薬剤の不正検知」ではなく、

1. オピオイド系薬剤に限定
2. 1病棟で試行
3. 在庫差異と廃棄記録の不一致を検出
4. 誤検知率と監査時間を測定
5. 効果を確認して対象を拡張

という順序にする。

### 7. 成功する起業家の行動特性を評価軸にする

ヘルスケア起業では、アイデアの新規性だけでなく、以下を評価する。

- 医療現場への継続的なアクセス
- 不確実な状況での仮説検証
- 臨床家・研究者・患者との協働能力
- 規制・倫理上の制約への対応力
- 長い販売サイクルへの耐性
- 失敗からの学習速度
- 技術と事業の両方を理解する能力

採用や起業家支援プログラムでは、ピッチの上手さだけでなく、現場検証の質を評価できる。

### 8. SUD領域における信頼をプロダクト要件にする

依存症領域では、データ漏洩、偏見、監視されている感覚、不適切なリスク分類が利用継続を損なう。

**具体的な設計要件**

- データ収集目的を明示する
- 患者が記録の共有範囲を選べるようにする
- AIの判定理由を説明可能にする
- 予測結果を懲罰や排除に使わない
- 誤判定の訂正手続きを用意する
- 当事者を製品評価に参加させる

## 他分野との接続

### 1. 医学・臨床科学

**接続する概念**

- 疾患メカニズム
- 治療効果
- 臨床アウトカム
- リスク層別化
- 再発予防

**転用例**

SUD向けAI製品を作る場合、機械学習の精度だけでなく、医師が介入可能なリスク因子を提示し、実際の治療方針の改善につなげる必要がある。

### 2. 公衆衛生・疫学

**接続する概念**

- 集団レベルのリスク
- 健康格差
- 介入の費用対効果
- 地域別の需要推計
- 予防と早期介入

**転用例**

地域ごとの過量摂取、救急搬送、治療中断のデータを組み合わせ、支援サービスを配置する地域を決める。単一患者への最適化ではなく、地域全体のアウトカム改善を評価する。

### 3. データサイエンス・AI

**接続する概念**

- 異常検知
- 予測モデル
- リスクスコア
- 自然言語処理
- プライバシー保護
- 公平性・説明可能性

**転用例**

薬剤不正流用の検知システムでは、単純なルールベース検知から始め、処方、投与、廃棄、在庫、職員アクセスログを組み合わせて異常を検出する。ただし、特定職種や患者群への偏った誤検知を監視する必要がある。

### 4. 行動科学・心理学

**接続する概念**

- 動機づけ
- 習慣形成
- 行動変容
- スティグマ
- 自己効力感
- 再発トリガー

**転用例**

服薬・通院支援アプリでは、単なる通知回数の最大化ではなく、患者が通知を受け入れやすいタイミング、失敗時に責められない表現、支援者へのエスカレーション方法を設計する。

### 5. デザイン・HCI

**接続する概念**

- 人間中心設計
- サービスデザイン
- ユーザーリサーチ
- 共創
- ペルソナ
- ジャーニーマップ

**転用例**

当事者、家族、医師、ソーシャルワーカーのそれぞれについて、相談開始から治療継続までの体験を可視化する。アプリ画面だけでなく、電話、対面、緊急時の連絡経路も含めてサービスを設計する。

### 6. 経営学・起業論

**接続する概念**

- 顧客発見
- 問題・解決策適合
- ビジネスモデル
- ピボット
- 競争優位
- スケール戦略

**転用例**

「SUD患者向けアプリを作る」ではなく、「病院の再入院率を下げる」「保険者の高額医療費を抑える」「薬剤管理の監査時間を削減する」のように、支払者が認識する価値に変換する。

### 7. オペレーション・サプライチェーン

**接続する概念**

- 追跡可能性
- 在庫管理
- 例外処理
- 内部統制
- 監査ログ
- プロセス改善

**転用例**

薬剤の入荷、保管、払い出し、投与、廃棄の各工程にデジタル記録を付け、在庫差異が生じた地点を特定する。AI導入前に、そもそものデータ欠損や業務フローの不整合を改善する。

### 8. 政策・規制・法務

**接続する概念**

- 医療データ保護
- 医療機器規制
- 薬物政策
- 説明責任
- 同意
- 責任分界

**転用例**

SUD患者の再発リスクをスコア化する製品では、予測結果を保険加入拒否、雇用上の不利益、治療アクセス制限に使わないためのガバナンスを設計する。

### 9. 倫理・社会科学

**接続する概念**

- スティグマ
- 自律性
- 公平性
- 当事者性
- インフォームド・コンセント
- パワー・アシンメトリー

**転用例**

「不正流用の可能性が高い職員」や「再発リスクが高い患者」といった分類を導入する場合、分類結果が監視・処罰・排除につながらないよう、利用目的、異議申立て、人的レビューを制度化する。

### 10. 社会起業・インパクト評価

- 社会的インパクト
- アウトカム指標
- 持続可能性
- 当事者参加
- 費用対効果
