## Key points
- Causal inference from observational data aims to estimate the impact of an intervention on an outcome without the ability to perform active randomized controlled trials.
- The Conditional Average Treatment Effect (CATE) and the Average Treatment Effect (ATE) are key metrics defined using the mathematical framework of potential outcomes.
- Simpson's paradox can lead to incorrect conclusions if underlying population distributions (confounders) are not accounted for, as shown in an example comparing COVID-19 case fatality rates between countries.
- Covariate adjustment involves learning a model to predict outcomes based on covariates and treatment. Incorrect assumptions about the model class (e.g., assuming linearity for non-linear data) can lead to highly inaccurate causal conclusions.
- Machine learning models like Gaussian Processes and Neural Networks (e.g., using shared representations with separate heads for different treatments) can be effective for covariate adjustment.
- Matching is an intuitive, non-parametric causal inference method that uses the nearest neighbor's outcome to estimate counterfactuals. It is mathematically equivalent to covariate adjustment using a nearest-neighbor classifier.
