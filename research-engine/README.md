# AIエージェント信頼性・コスト最適化研究エンジン

このパイロットは、AIエージェントの自律修復、品質評価、コスト最適化について、出典付きの知識を慎重に増やすための基盤である。

## 最初の問い

> どの処理を低コストモデルへ委譲し、どの失敗だけを上位工程へ回せば、品質基準を保ちながら費用を下げられるか。

## 境界

- MIT講義は概念候補の発見に使う。講義の整形版やAIの出力を、外部事実の根拠として扱わない。
- 外部資料は、取得条件・保存条件を確認できる公開資料だけを対象にする。
- AIが作るものはすべて提案であり、確立した前提に使う主張は人間確認を要する。
- 外部への送信、公開、購入、ログインが必要な取得は自動で実行しない。
- `research.sqlite3`は構造化データの正本、原資料ファイルは内容の正本、Markdownレポートは派生物である。

## 最小ループ

```text
知識の穴 → 調査質問 → 計画 → 取得 → 抽出 → 反証探索
        → 未審査の候補を保存 → 人間レビュー → 採用 / 保留
```

現在はPhase 0である。DB、スキーマ、予算、監査を先に作り、外部APIや自動取得は有効化しない。

## 実行

```powershell
cd knowledge-engine/research-engine
python init_db.py
python status.py
```

通常のAI処理を有効化する前に、`config/model-policy.json`の`dry_run`を確認する。
