# 4条件比較ランナー

このランナーは、モデルの出来を決めるものではない。各条件で同じ入力・上限・評価項目を渡し、比較可能な実行記録を残すための決定論的な土台である。

条件は `baseline`、`dsm_only`、`icd_only`、`dsm_and_icd`。

- DSM: 依存関係と重複した情報フローを可視化する。
- ICD: メッセージの必須フィールド、許容する版、失敗時の扱いを固定する。
- この段階では、各条件が有利になるような結果をシミュレートしない。ランナーは入力・設定・結果を記録するだけ。

```powershell
cd knowledge-engine/research-engine
python .\experiment\run_fixture.py
```

本物の低コストモデル実験は、同じログ形式を使うアダプターを追加してから実行する。
