# 次世代RAG（GraphRAG / ハイブリッドリトリーバル）

## ユーザーの主張

単なる「文章を細切れにして類似度検索する（Vector RAG）」のは過去の手法である。最先端では、以下を組み合わせる。

- 社内文書から、人物、プロジェクト、製品、規定などのエンティティの関係性ネットワークを自動抽出し、ナレッジグラフと連動させる。点ではなく網で知識を引く。
- 「公式規定」「過去PJの文脈」「現場のTips」にレイヤーを分け、クエリの意図に応じて参照先を動的に切り替える。
- 検索結果の上位候補を、LLM特化のリランカーモデルに通し、「本当に質問に答えるために必要な文脈か」をミリ秒単位で再順位付けする。
