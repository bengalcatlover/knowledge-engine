# 仕様駆動マルチエージェント自己修復ループ

## ユーザーの主張

プロンプトを一発叩いて終わりではなく、複数のAIエージェントを協調させて開発させる。

- ざっくりした要望から、要件定義エージェントが分厚い仕様（Markdown / PRD）を自動展開し、DBスキーマ・API設計・テストケースを自動生成する。
- Claude CodeやCline/Roo CodeのようなCLI・ヘッドレスエージェントが、ローカル環境で直接ファイルを生成・編集し、自律的に実装する。
- AIがテストを実行し、エラーログが出たら、人間を介さずに「エラー解析 → コード修正 → 再テスト」をテストが通るまで自動的にループする。
- 朝起きたら、ユニットテストとE2Eテストがすべて通ったコードがGitに上がっている状態を作る。

## 未確定事項

- 複数のAIエージェントを協調させる具体的な構成や役割分担。
- 要件定義エージェントが仕様を展開する際の入力形式と詳細な出力形式。
- 自己修復ループを開始する条件、終了条件、失敗時の扱い。
- 自律試行の回数上限をどう決めるか。
- 人間がどの段階でどう関与するか（レビュー範囲・承認粒度）。
- 利用する実行環境、権限管理、変更範囲の制御方法。
