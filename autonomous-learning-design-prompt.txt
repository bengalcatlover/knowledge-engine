あなたは、長期運用される自律研究・知識生産システムのアーキテクトです。

ユーザーは、MIT OCW講義を入口として概念候補を抽出し、独立資料・論文・公的資料・標準規格を調査し、主張・根拠・条件・限界・概念間の関係をKnowledge DBへ蓄積するAIを作りたいと考えています。AIは知識の穴、矛盾、重要な未解決点を見つけ、自分で次の調査課題を提案・実行し、慎重に知識を増やす必要があります。

目標は、次の循環です。

知識グラフを読む → 知識の穴・矛盾・重要度を検出 → 学習課題を作る → 独立資料を探索 → 主張と根拠を抽出 → 反証・条件・矛盾を検査 → candidateとして保存 → 評価と承認を経てacceptedへ昇格

過学習、自己生成物の循環引用、同一資料群への偏り、もっともらしい誤り、無制限のAPI費用、古い知識の上書きを避ける必要があります。AIが提案だけで止まらず、調査・検証・記憶更新まで自律的に進める一方、外部への実害がある行為は人間承認を残します。

日本語Markdownで、次を具体的に設計してください。

1. システムの構成要素とデータモデル（source, concept, claim, evidence, relationship, hypothesis, question, experiment, decision, output）。
2. 自律学習ループの状態遷移、各状態での入出力、失敗・停止・再試行条件。
3. candidate / supported / verified / disputed / retired の昇格・降格基準。
4. 過学習・偏り・自己引用循環・誤情報拡散を防ぐ具体的な仕組み。
5. 概念グラフで、科学的関係・出典関係・類推・ユーザー判断を混同しないエッジ設計。
6. Codex/Claude Codeが使える最小実装から、将来のマルチエージェント研究システムへ進む段階的ロードマップ。
7. 最初のパイロットテーマと評価指標。

抽象論で終わらず、最小構成、データの正本、監査ログ、評価セット、予算制限、人間承認点を明記してください。既存の一般的なRAG/GraphRAGへの過度な依存は避け、何を決定論的コードに置き、何をAIに任せるかを明確にしてください。
