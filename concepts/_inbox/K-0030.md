## Definition

主成分分析（PCA）とは、高次元データの共分散行列を固有値分解し、分散を最大化する直交軸（主成分）を順に抽出することで、データの本質的な構造を少数の次元で捉える手法である。数学的には、中心化されたデータ行列 X の共分散行列 C = XᵀX/(n-1) の固有ベクトルが主成分方向を、対応する固有値が各方向の分散を与える。SVD（特異値分解）を通じて計算されることが多い。

## Mechanism

1. データ行列 X（n×p）を列ごとに中心化する（各変数の平均を引く）。
2. 共分散行列 C = XᵀX/(n-1) を構成する（p×p 対称半正定値行列）。
3. C を固有値分解する：C = VΛVᵀ。V の列が主成分方向、Λ の対角成分 λ₁ ≥ λ₂ ≥ ... ≥ λₚ ≥ 0 が各成分の分散である。
4. 実務上は X = UΣVᵀ（SVD）を計算し、V の最初の k 列を取ることで k 次元に射影する。
5. 寄与率 λᵢ/Σλⱼ と累積寄与率を計算し、スクリープロットで次元数 k を決定する。
6. 射影後のデータ Z = XV_k（n×k）を下流タスクに使う。

## Assumptions

- 変数間の関係が線形であること。非線形構造にはカーネル PCA や t-SNE が必要である。
- 分散が大きい方向に情報がある、という前提を置いている。ノイズの分散が大きい場合、主成分がノイズを捉える。
- 入力変数のスケールが統一されていること。単位が異なる変数を混ぜる場合、標準化（相関行列の PCA）が必要である。
- データが多変量正規分布に従う場合、主成分は統計的に独立になるが、一般には無相関であるに留まる。

## Boundary Conditions

- p >> n（変数数がサンプル数より遥かに多い）のとき、共分散行列の推定自体が不安定になる。スパース PCA や正則化が必要になる。
- 次元の呪い：高次元空間では距離の集中が起き、ユークリッド距離による類似度が意味を失う場面がある。
- 寄与率が緩やかに減少するデータでは、少数の主成分による圧縮が有効でない。
- 主成分は元の変数の線形結合であるため、個々の成分の解釈が困難なことが多い。

## Failure Modes

- スケール標準化を忘れると、単位が大きい変数が第一主成分を支配する。
- 寄与率のみで k を決定し、下流タスクの性能で検証しないと、情報を捨てすぎるか残しすぎる。
- 外れ値に PCA は敏感であり（共分散行列が歪む）、ロバスト PCA を使わないとノイズ成分が主成分に混入する。
- 非線形多様体上のデータに線形 PCA を適用すると、構造を破壊する次元削減になる。

## Business Transfer

- **scenario**: RAGの埋め込みベクトル（768次元など）を PCA で圧縮し、検索速度を改善しつつ検索精度の劣化を許容範囲に抑える。
  **domain**: 検索・情報検索
  **caveat**: 圧縮次元数は寄与率だけでなく検索精度（Recall@k）で決定する必要がある。埋め込み空間の非線形性が強い場合、線形圧縮は情報損失が大きい。

- **scenario**: センサーデータの多変量時系列に PCA を適用し、正常時の主成分空間からの逸脱を異常検知に使う。
  **domain**: 製造・IoT
  **caveat**: 非定常なプロセスでは共分散構造が時間変化するため、ウィンドウ分割やオンライン PCA が必要になる。

- **scenario**: 金融資産のリターン行列に PCA を適用し、市場ファクター（第一主成分≒市場全体）を抽出してポートフォリオのリスク分解に使う。
  **domain**: 金融・リスク管理
  **caveat**: 危機時には相関構造が急変するため、平時の共分散行列に基づく主成分が無効化する。動的共分散モデルとの併用が望ましい。

## Examples

- 画像データ（784次元のMNIST）を50次元に圧縮しても分類精度がほぼ維持される。
- 遺伝子発現データ（数万次元）の PCA で、集団の遺伝的構造（祖先構成）を二次元で可視化する。
- テキスト埋め込みの PCA により、意味的に近い文書群のクラスター構造を視覚化する。

## Non-examples

- t-SNE や UMAP は非線形次元削減であり、PCA の線形射影とは原理が異なる。
- オートエンコーダによる次元削減は、非線形変換を含むため PCA の一般化ではあるが、固有値分解の枠組みではない。
- 因子分析は潜在変数モデルであり、PCA のような分散最大化とは目的が異なる（共通因子 vs 主成分）。
