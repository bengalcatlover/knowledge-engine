# あきらぐ（知識OS）とは何か

## 一言で言うと

「根拠を追跡できる世界モデルを、勝手に増殖させるOS」

人間が餌（情報）を与えなくても、知識を自律的に拾い、検証し、構造化し、拡大していくシステム。LLMの知識を丸ごと信じるのではなく、一つ一つの主張に対して学術論文のDOIまで遡って検証し、嘘を12〜28%の精度で自動検出して弾く。

---

## 既存のものと何が違うのか

### vs. ChatGPT / Claude などの汎用LLM

| 観点 | 汎用LLM | あきらぐ |
|------|---------|---------|
| 知識の根拠 | 学習データに埋没。「なぜそう言えるのか」を答えられない | 全ての主張（claim）に論文DOI・出典・検証結果が紐付く |
| ハレーション | 自信満々に嘘をつく。ユーザーが気づかない限り訂正されない | 4層検証パイプラインで偽DOIを自動除去（12-28%が偽と判明） |
| 知識の成長 | モデル再学習まで知識は固定。ユーザーの質問は消える | 穴（Gap）を自動検出し、論文を拾い、検証し、自律的に成長する |
| 構造 | フラットな文章生成。知識間の関係は暗黙的 | 5層構造（基礎科学→科学→宇宙→オブジェクト→実践）で知識を階層化。エッジで関係を明示 |
| 矛盾 | 気づかない。同じ質問でも回答が変わる | 矛盾する主張はCONTRADICTSエッジで検出・隔離。人間レビューキューへ |

**本質的な違い**: LLMは「もっともらしい文章を生成する機械」。あきらぐは「根拠に遡れる知識を蓄積・検証・構造化するOS」。LLMはあきらぐの部品（知識の候補を提案する役）に過ぎない。

### vs. Wikipedia / ナレッジベース

| 観点 | Wikipedia | あきらぐ |
|------|-----------|---------|
| 更新 | 人間ボランティアが編集 | 自律的に穴を検出→論文を拾う→検証→登録のサイクルが自動で回る |
| 根拠追跡 | 出典はあるが、主張と出典の紐付けは人間任せ | 主張（claim）と根拠（evidence）が構造的に1対1で紐付く。追跡経路を機械的に辿れる |
| 品質保証 | 編集合戦、荒らし | Policy engine（stale伝播、独自証明保護、HYP隔離）が品質を構造的に保証 |
| 構造 | 記事単位のフラット構造 | 5層の階層構造＋型付きエッジで知識間の関係を形式化 |

### vs. Google Scholar / Semantic Scholar

| 観点 | 学術検索 | あきらぐ |
|------|---------|---------|
| 機能 | 論文を探す道具 | 論文から知識を抽出し、構造化し、他の知識と接続する |
| 出力 | 論文リスト | 根拠付きの世界モデル。「なぜこう言えるのか」を5層で遡れる |
| 自律性 | 検索は人間がする | 穴を検出し、検索クエリを自動生成し、結果を検証して取り込む |

### vs. Notion / Obsidian などのPKM（Personal Knowledge Management）

| 観点 | PKM | あきらぐ |
|------|-----|---------|
| 知識の追加 | 人間が書く | 自律的に増殖する |
| 根拠 | メモに書いた人の記憶次第 | 4層検証済みのDOIが構造的に紐付く |
| 関係性 | 人間がリンクを張る | エッジ推論エンジンが自動で関係を検出・提案 |
| 品質 | 人間の注意力次第 | Policy engineとサーキットブレーカーで品質保証 |

### vs. Knowledge Graph（Google Knowledge Graph, Wikidata等）

| 観点 | 既存KG | あきらぐ |
|------|--------|---------|
| 対象 | エンティティの事実（「東京の人口は1400万」等） | 科学的主張とその根拠の構造化。「なぜそう言えるか」が中心 |
| 検証 | 出典はあっても検証は手動 | CrossRef→OpenAlex→Semantic Scholar→Unpaywallの4層自動検証 |
| 成長 | 人間が追加するか、構造化データから抽出 | Gap detectorが穴を見つけ、Knowledge Amplifierが論文を拾い、自律的に成長 |
| LLMとの関係 | LLMの学習データとして使われる | LLMを「知識の候補生成器」として使い、検証済みの知識だけを取り込む |

## 技術アーキテクチャ

### 5層世界モデル
```
foundation（基礎科学）: 数学的公理、論理体系
    ↑ DERIVES_FROM
science（科学）: 検証可能な理論・定理
    ↑ FORMALIZED_BY
universe（宇宙）: 理論の適用範囲・条件
    ↑ HAS_SCOPED_INSTANCE
object（オブジェクト）: 具体的な事例・実験結果
    ↑ GUIDES_TEST_DESIGN
practice（実践）: 問い・行動・検証
```

### ハレーション除去パイプライン
LLMが提示したDOI付き論文を4段階で検証する:
1. **CrossRef**: DOIが実在するか確認
2. **OpenAlex**: フォールバック + 引用数 + OA状態
3. **Semantic Scholar**: abstractを取得し、主張と論文の意味的一致を判定
4. **Unpaywall**: OA PDF URLの取得

実測で、LLMが提示するDOIの12〜28%が架空であることが判明。これを自動で弾く。

### 自律成長サイクル（7フェーズ）
```
1. repair   — Gap検出（G1未支持claim / G2欠落インスタンス / G3未検証エッジ）
2. extract  — evidence→abstract取得→LLMでclaim抽出→重複判定→ノード帰属→登録
3. grow     — unresolvedなclaim→LLM分類→provisionalノード生成
4. relate   — co-evidence候補からエッジ推論→LLM検証→HYP_EDGE隔離→G3解消
5. promote  — provisionalノードの昇格判定（independent evidence >= 2）
6. expand   — ドメイン拡大（100ノード後に自動化予定）
7. audit    — 品質メトリクス集計 + サーキットブレーカー判定
```

1サイクルで最大16件のevidenceから31件のclaim自動抽出、5ノード自動生成、エッジ推論の実績あり。evidence 23→69、支持関係 41→142に自律成長。

### 暴走防止（サーキットブレーカー 5条件）
1. ハレーション棄却率 > 40% → 停止
2. 暫定ノード比率 > 30%（N>=50で判定）→ 拡大凍結
3. 矛盾滞留 > 10件 → 人間レビュー完了まで停止
4. 成長率 > 20%/サイクル（N>=50で判定）→ 停止
5. 3サイクル連続で新verified claim < 3 → 休止（収束検知）

加えて:
- 自動生成物の再消費深度上限（derivation_depth <= 3）→ 幻覚の増幅ループを遮断
- 冪等キー付きgap台帳で同一穴への無限リトライを防止
- 予算制御: LLM 200コール/サイクル、新ノード20/サイクル、wall time 30分

## OOP的な解釈

あきらぐの構造はオブジェクト指向プログラミングと相似形を成す:

| OOP | あきらぐ |
|-----|---------|
| クラス定義 | science/universe層のノード（不変条件=claim、契約=FORMALIZED_BY先の形式化） |
| インスタンス | object/practice層のノード（具体的な事例・実験結果） |
| new演算子 | HAS_SCOPED_INSTANCE エッジの生成 |
| Extract Superclass | 複数の孤児インスタンスから共通構造を抽出→新しいscience層ノードを生成 |
| 型検査器 | Gap Detector（未実装インターフェース・断絶した継承を検出） |
| コード生成器 | Knowledge Amplifier（穴に対する実装候補を外部文献から合成） |
| コンパイラの最終ゲート | Policy Engine |

## 可能性

### 短期（今 — 40ノード稼働中）
- **ハレーション除去付きのリサーチエンジン**: LLMに聞くだけでは信じられない → あきらぐは根拠まで遡れる
- **個人の知識基盤**: 調べたことが消えない。構造化されて蓄積され、次の調査の起点になる
- **自律パイプライン実証済み**: 8モジュールの7フェーズサイクルが実際に回り、6ドメインに跨る知識が自律的に増殖している

### 中期（100〜1000ノード規模）
- **ドメイン横断の知識発見**: 第二価格オークションの均衡理論と情報理論の最適符号化に構造的相似がある、といった発見を自動で行う（relation_engineの初期版が既にドメイン間エッジを生成中）
- **企業の知識資産化**: 属人知を構造化し、根拠付きで組織に蓄積する（RAGの進化形）
- **ファクトチェックエンジン**: 任意の主張に対して根拠を自動追跡し、支持/反証を判定

### 長期（10000ノード〜）
- **自律的に成長する世界モデル**: 人間が寝ている間に知識が増え、構造化され、新しい関係が発見される
- **知識のOS**: アプリケーション（記事生成、意思決定支援、教育、研究支援）はこのOS上で動く。知識そのものがプラットフォームになる
- **LLMの知識を「洗浄」するインフラ**: LLMが持つ膨大な知識を、検証済みの構造化知識に変換する装置。LLMの上流に位置するメタシステム

### 競争優位
1. **LLMをそのまま信じない**: 4層検証で嘘を弾く仕組みを最初から組み込んでいる
2. **構造が知識を生む**: 穴の検出→充填の再帰ループにより、知識が自律的に増殖する
3. **根拠追跡可能性**: 全ての主張にDOI付き論文まで遡れる。「なぜそう言えるのか」に常に答えられる
4. **暴走しない自律性**: サーキットブレーカー、冪等台帳、derivation_depth上限で品質を構造的に保証

### ドメイン
1. 第二価格オークション（Vickrey 1961）
2. 情報理論（Shannon 1948、符号化定理）
3. メカニズムデザイン（VCG、Myerson最適オークション、GSP広告オークション）
4. 情報経済学（Bayesian persuasion、rational inattention、Blackwell順序）
5. 契約理論（逆選択、モラルハザード、principal-agent）
6. ベイズ意思決定理論（Bayesian Nash均衡、シグナリング）

### 自律成長の実績
- 1サイクルで最大16件のevidenceからclaim自動抽出
- 1サイクルで最大31件のnew claim生成
- 1サイクルで最大5ノード自動生成（LLM分類→provisional）
- LLM提示DOIの12-28%がハレーション → 4層検証で自動除去
- relation_engineがco-evidence候補から有意なエッジのみ生成（棄却率90%の厳格判定）
- K-0007シンクノード問題をストップワード除去+閾値引き上げで解消

### 品質保証
- 契約テスト9本全通過（不変条件の品質ゲートを機械的に保証）
- independent_coverage: 30%（evidence_miner自己参照を除外した真の検証率）
- サーキットブレーカー5条件（ハレーション率、provisional比率、dispute、成長率、収束検知）
- HYP_EDGE隔離（LLM直感エッジは事実グラフから分離）
- GPT-6 Astraの生回答 vs あきらぐの回答を比較 → Astraは実在しないDOIを引用していた。あきらぐは全出典が検証済み
