## 人間レビュー時の記録

カードごとに次のいずれかを決める。

- `approved`: 根拠、本文、関係を確認し、ユーザーが採用する。
- `revise`: 修正箇所と不足根拠を指定する。
- `merge_candidate`: 重複のため統合候補にする。二者レビューを行う。
- `defer`: 追加根拠が必要。必要な講義・資料・主張を明記する。

承認済みカードだけで、[評価セット](../evaluation_questions.yaml)の20問を再評価する。
