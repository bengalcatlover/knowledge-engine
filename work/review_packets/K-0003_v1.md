# K-0003 — ナッシュ均衡と戦略的相互作用

## このカードが説明すること

他者の戦略を所与とすると、誰も単独変更で利得を増やせない状態を扱う。均衡は最善・公正・協力的な結果を意味しない。

## 確認済みの検索断片

- [MIT OCW: Lecture 5, Nash Equilibrium](https://www.youtube.com/watch?v=ftCXguW2k4o)
  - "both players are playing a best response to each other's strategy"
- [MIT OCW: Lecture 8, Backward Induction](https://www.youtube.com/watch?v=VHex0a2JFWI)
  - "every extensive form game with perfect information has a pure strategy Nash equilibrium"

## 承認前に確認する点

1. 最適反応・均衡・社会的最適を区別しているか。
2. 完全情報の逐次ゲームの結果を、同時手番・不完全情報に無条件で広げていないか。
3. AIエージェントや価格競争への記述を、講義由来の事実ではなく応用提案として区別すべきか。
4. Source Referencesが講義群IDだけで、主張単位のURL・位置・引用が不足している。
